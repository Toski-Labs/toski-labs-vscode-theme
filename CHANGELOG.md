# Changelog — Toski Theme

## 1.0.0 - 05/10/2026

- Primeira versão / First release.
- **Toski Dark** e **Toski Light**, com a paleta da Toski Labs.
- Cobertura de TypeScript/JavaScript, TSX/JSX, Swift, JSON, Markdown, CSS/SCSS, HTML, YAML, shell e diff, com destaque semântico ativado.
- Terminal com as mesmas cores ANSI do tema Toski para iTerm2.
- Todo texto de código e interface com contraste mínimo de 4,5:1 (fundo, linha atual, seleção, busca, diff e listas).
